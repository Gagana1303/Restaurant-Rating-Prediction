# Restaurant-Rating-Prediction
This project predicts restaurant ratings using machine learning techniques, including both regression and classification models. The goal is to understand factors affecting restaurant ratings and build models to predict them accurately.

# Project Structure
* Data Preprocessing: Cleans and encodes the dataset.
* Exploratory Data Analysis: Visualizes feature correlations and distributions.

# Modeling:
* RandomForestRegressor: Predicts exact ratings.
* RandomForestClassifier: Classifies ratings into categories (e.g., 'Excellent', 'Good', 'Poor').

# Usage
* Clone this repository: git clone https://github.com/Gagana1303/Restaurant rating prediction.git   cd Restaurant rating prediction
* Install dependencies: pip install -r requirements.txt
* Run the notebook: jupyter notebook Restaurant rating predictor.ipynb

# Results
* Regression RMSE: Approximately 0.35 (example; based on actual output).
* Classification Accuracy: Around 87% accuracy in predicting rating categories.
* Important Features: online_order, book_table, and cost_for_two were among the top predictors.

# Conclusion
This project demonstrates that restaurant rating prediction is feasible using structured data and machine learning. The classification model showed strong performance, making it suitable for customer segmentation or personalized recommendations
